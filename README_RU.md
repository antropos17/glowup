# Переезд в Claude Code: что делать

Этот архив кладётся поверх кода игры. Кода в нём нет: код лежит в `glowup-30.zip` из чата «Продакшн».

## Шаги

1. Распакуй `glowup-30.zip`. Получится папка `glowup`.
2. Распакуй этот архив в ту же папку `glowup` с заменой файлов.
3. Открой терминал в папке `glowup` и запусти `claude`.
4. Вставь первым сообщением блок из `docs/prompts/01-first-session.md`.
5. Дальше дни пишутся командой `/write-day 2`, потом `/write-day 3` и так до 7.

## Что внутри

| Файл | Зачем |
|---|---|
| `CLAUDE.md` | Главный контекст для Claude Code, на английском |
| `docs/HANDOFF.md` | Что сделано в трёх чатах и что осталось |
| `docs/DESIGN.md` | Все решения брейнсторма на 30 дней |
| `docs/DEMO_SCRIPT.md` | Сетка 7 дней, день 1, как его метки отзываются дальше |
| `docs/CONTENT_FORMAT.en.md` | Формат карточек, перевод на английский |
| `docs/AD_30S.md` | Заметки по рекламному ролику |
| `docs/progress.json` | Статус по дням, его обновляет Claude |
| `docs/prompts/01-first-session.md` | Первый промпт |
| `.claude/commands/write-day.md` | Команда `/write-day` |

## Как устроен язык

- Claude думает, читает и пишет документы, код и коммиты на английском.
- Всё, что видит игрок, остаётся на русском: тексты карточек, чат, интерфейс.
- Отвечает вам Claude на русском.

## Что стоит знать

- Архив собран по трём чатам и документам проекта. Сам код я не видел, поэтому первый промпт сначала сверяет документы с кодом и чинит расхождения.
- Ролик (`30-days-ad.mp4` и архив проекта) лежит в чате с рекламой, сюда он не входит.
- Если в папке `glowup` уже есть свой `CLAUDE.md`, сравни его с новым перед заменой.
