# Формат контента: как писать сценарий, чтобы он сразу работал в игре

Сценарий лежит в папке `content/` в виде JSON. Движок читает эти файлы как есть,
код править не нужно. После правок запусти `npm run check:content`: проверка
найдёт битые ссылки и карточки, на которых игрок может застрять.

Этот файл можно целиком отдать в чат, где пишется сценарий, и просить
карточки сразу в этом формате.

## Файлы

| Файл | Что в нём |
|---|---|
| `balance.json` | Числа игры: дней, энергии в день, стартовый шанс и его потолок, сколько дней уже написано (`contentDays`) |
| `days.json` | По строке на день: название, подарок за день, строка «что будет завтра» |
| `problems.json` | Шаблоны проблем: прыщи, вес, зубы и так далее |
| `archetypes.json` | Герои: внешность и набор проблем (минимум 5) |
| `crushes.json` | Краши и пул их скрытых вкусов |
| `tastes.json` | Вкусы: что должно быть правдой, чтобы вкус сыграл в плюс |
| `items.json` | Предметы магазина |
| `chat.json` | Фразы краша по ситуациям, около 10 вариантов на ситуацию |
| `hints.json` | Подсказки, которые сами попадают в блокнот |
| `rumors.json` | Слухи для ленты |
| `cards/*.json` | Карточки. Файлов может быть сколько угодно, в каждом массив |

## Карточка

```json
{
  "id": "e_mom_derm",
  "kind": "event",
  "title": "Мама звонит",
  "speaker": "Мама",
  "text": "«Я нашла телефон дерматолога. Запиши, пока не забыл».",
  "when": { "days": [1, 6], "parts": ["morning", "day"], "requires": [{ "problem": "skin", "gte": 30 }] },
  "choices": [
    {
      "id": "book",
      "label": "Записаться на завтра",
      "cost": { "energy": 2, "coins": 50 },
      "outcomes": [
        { "text": "Запись на завтра, 11:30.", "effects": [{ "hint": "derm_number" }, { "queue": "q_derm_visit", "inDays": 1 }] }
      ]
    },
    {
      "id": "later",
      "label": "Сказать «ага, позвоню»",
      "outcomes": [{ "text": "{hero} возвращается к сериалу.", "effects": [{ "flag": "brushed_mom_off" }] }]
    }
  ]
}
```

### Виды карточек (`kind`)

| Вид | Когда приходит |
|---|---|
| `story` | Узкое дерево, история с крашем. Приходит первой, как только подошли день и условия |
| `event` | Широкая колода. Выпадает случайно по весу среди подходящих |
| `quest` | Шаг квеста. Сам не выпадает, его ставит в очередь эффект `queue` |
| `chat` | Развилка в переписке. Выбранный вариант уходит в чат как сообщение героя |
| `action` | Действие из меню плюса: пробежка, душ, сон. Игрок выбирает его сам |

По нажатию плюса игра сначала отдаёт шаги из очереди, потом сюжет по порядку в файле.
Когда обязательного не осталось, открывается меню «Чем заняться»: действия (`action`)
и, если в колоде есть подходящие события, строка «посмотреть, что происходит вокруг».
Из колоды за одно время суток выпадает не больше `balance.cardsPerPart` карточек.

Сюжет ждёт игрока. Утренняя сюжетная карточка придёт и днём, и вечером того же дня,
если игрок зашёл позже. У остальных видов `parts` значит ровно это время суток.

Действие с одним вариантом выполняется сразу из меню. Действие с несколькими
вариантами открывается как обычная карточка (так сделан сон).

### Когда карточка может выпасть (`when`)

- `days`: с какого по какой день, включительно.
- `parts`: в какое время суток: `morning`, `day`, `evening`, `night`.
- `requires`: условия, должны выполниться все.
- `weight`: вес в колоде, по умолчанию 1. Вес 3 выпадает втрое чаще.
- `cooldownDays`: через сколько дней карточка может выпасть снова. Без этого поля она выпадает один раз за игру.

### Правило без тупиков

В каждой карточке должен быть хотя бы один вариант без цены и без условий.
Проверка контента это требует. Так игрок никогда не упирается в стену,
даже с нулём энергии и монет. Действиям из меню это правило не нужно:
их игрок выбирает сам.

## Исходы

У варианта может быть несколько исходов. Сначала отбираются те, у которых
выполнены условия `if`, потом из них выбирается один по весу `weight`.

У исхода есть два необязательных поля:

- `hint`: два-три слова про исход. Если у варианта несколько исходов с `hint`,
  игрок видит под кнопкой честные шансы словами: «часто: смеются, иногда: тишина».
  Слово берётся из весов: от 60% «часто», от 25% «иногда», меньше «редко».
- `why`: причина рядом со шкалой шанса, если шанс изменился: «−2: Сообщение с сердечком».
  Без `why` показывается название карточки.

Так делается «очевидное решение может навредить»:

```json
"outcomes": [
  { "weight": 3, "text": "От мази стало хуже.", "effects": [{ "problem": "skin", "add": 10 }, { "flag": "derm_failed" }] },
  { "weight": 2, "text": "Воспаление стало спадать.", "effects": [{ "problem": "skin", "add": -14 }] }
]
```

И так делается «уставший герой косячит»:

```json
"outcomes": [
  { "if": [{ "stat": "energy", "lte": 1 }], "text": "Сил спорить с собой не осталось.", "effects": [{ "problem": "weight", "add": 5 }] },
  { "if": [{ "stat": "energy", "gte": 2 }], "text": "Получилось пройти мимо.", "effects": [{ "problem": "weight", "add": -2 }] }
]
```

## Условия

Используются в `when.requires`, `choice.requires`, `outcome.if` и во вкусах.
К числам подходят `eq`, `gte` (не меньше), `lte` (не больше).

| Условие | Смысл |
|---|---|
| `{ "flag": "lied_to_mom" }` | Метка стоит |
| `{ "flag": "lied_to_mom", "set": false }` | Метки нет |
| `{ "flagAge": "lied_to_mom", "gte": 2 }` | Метку поставили минимум 2 дня назад |
| `{ "problem": "skin", "gte": 30 }` | Уровень проблемы: 100 запущено, 0 решено |
| `{ "stat": "energy", "lte": 1 }` | `energy`, `coins`, `chance`, `affinity`, `day`, `streak` |
| `{ "counter": "smoke_free", "gte": 3 }` | Счётчик не меньше 3 |
| `{ "item": "cream" }` | Предмет есть в инвентаре |
| `{ "part": ["night"] }` | Сейчас это время суток |
| `{ "gender": "f" }` | Пол героя |
| `{ "archetype": ["andrey"] }` | Архетип героя |
| `{ "taste": "glasses", "revealed": true }` | У краша есть такой вкус, и игрок о нём уже знает |
| `{ "seen": "c01_reply" }` | Карточка уже была сыграна |
| `{ "any": [ ... ] }` | Хватит одного из условий |
| `{ "not": { ... } }` | Условие не выполнено |

## Эффекты

| Эффект | Что делает |
|---|---|
| `{ "problem": "skin", "add": -12 }` | Минус лечит, плюс ухудшает |
| `{ "stat": "energy", "add": 2 }` | `energy`, `coins`, `affinity` (отношение краша) |
| `{ "flag": "lied_to_mom" }` | Ставит метку и запоминает день |
| `{ "unflag": "lied_to_mom" }` | Снимает метку |
| `{ "item": "cream", "add": 1 }` | Даёт или забирает предмет |
| `{ "look": { "hair": "buzz" } }` | Разовое изменение внешности: стрижка, покраска, новая одежда |
| `{ "queue": "q_derm_visit", "inDays": 1, "part": "day" }` | Назначает шаг квеста на потом |
| `{ "chat": "warm" }` | Краш пишет фразу из ситуации `warm` в `chat.json` |
| `{ "write": "Привет!" }` | Герой пишет крашу |
| `{ "hint": "derm_number" }` | Подсказка в блокнот |
| `{ "rumor": "soda_teeth" }` | Слух в ленту |
| `{ "reveal": "glasses" }` | Раскрывает игроку скрытый вкус краша |
| `{ "modifier": { ... } }` | Длительное изменение, например абонемент в зал |
| `{ "log": "Строка в журнал" }` | Просто запись в журнал |
| `{ "counter": "smoke_free", "add": 1 }` | Меняет счётчик. Вместо `add` можно `set` |
| `{ "tomorrow": [ ... ] }` | Эффекты внутри сработают завтра утром: `{ "tomorrow": [{ "stat": "energy", "add": -1 }] }` |
| `{ "closeDay": true }` | Заканчивает день сейчас: кадр героя, карточка дня, награда. Так работает сон |

Шанс понравиться напрямую менять нельзя. Он считается сам: стартовый шанс
(`balance.chanceBase`), решённые проблемы, отношение краша (`affinity`) и совпавшие
вкусы, но не выше `balance.chanceCap`. Поэтому формулу можно честно показать игроку.

## Служебные метки и ключи

- Метка `chance_shown` открывает шкалу шанса на экране. Со второго дня шкала видна всегда.
- Метка `chance_note` со значением-строкой показывает подпись под шкалой:
  `{ "flag": "chance_note", "value": "Алина пока не знает, что ты существуешь" }`.
- Ситуации в `chat.json` с ключом, который начинается на `status_`, это не слова краша,
  а служебная строка в чате: «была в сети в 23:41, ответа нет».

## Конец дня

День заканчивается сам в 06:00 или раньше, если сработал эффект `closeDay`.
В этот момент игра сохраняет кадр героя для таймлапса и показывает карточку дня:
изменения показателей, главные решения, награду и строку про завтра.

За сыгранный день игрок получает `balance.dayCoins` монет и подарок из `days.json`.
За пропущенный день награды нет, а показатели ухудшаются на `regress`.

```json
{ "day": 1, "title": "Приглашение", "gift": "gum", "teaser": "Утром: сообщение от мамы" }
```

Когда кончаются написанные дни (`balance.contentDays`), игра показывает
«Продолжение следует».

## Память

Метка помнит день, когда её поставили. В любом тексте можно написать:

- `{hero}`: имя героя
- `{crush}`: имя краша
- `{day:lied_to_mom}`: день, когда поставили метку

Пример: `«Ты на {day:brushed_mom_off}-й день обещал позвонить врачу»`.
Карточке с таким текстом нужно условие на эту метку, иначе вместо дня будет знак вопроса.

## Проблемы и внешность

Уровень проблемы от 0 до 100 сам меняет картинку героя. Связь задаётся в `problems.json`:

```json
{ "id": "skin", "title": "Прыщи", "bar": "Кожа", "icon": "drop", "regress": 4,
  "look": [{ "param": "acne", "at0": 0, "at100": 100 }] }
```

- `regress`: на сколько становится хуже за каждый пропущенный день.
- `look`: какой параметр внешности двигает проблема.

Параметры внешности с числами: `weight` (0 худой, 50 в форме, 100 полный), `acne`,
`teeth`, `hairCare`, `posture`, `tired`, `mood`, `clothesCare`.

Параметры со списком значений меняются эффектом `look`:

- `hair`: `bald`, `receding`, `buzz`, `short`, `side`, `messy`, `curly`, `long`, `bob`, `ponytail`, `bun`
- `glasses`: `none`, `thick`, `taped` (толстая оправа с изолентой), `thin`, `round`
- `facial`: `none`, `stubble`, `patchy`, `beard`
- `neckline`: `wide`, `crew`, `v`, `collar`, `hood`, `lapel`
- `bottom`: `sweats`, `jeans`, `trousers`, `skirt`
- цвета в формате `#RRGGBB`: `hairColor`, `topColor`, `bottomColor`, `shoeColor`
- `skin`: тон кожи от 0 до 4

## Предметы

```json
{ "id": "cream", "title": "Крем от соседки", "blurb": "Мажется на ночь.", "icon": "tube",
  "price": { "coins": 40 },
  "limits": "Убирает часть прыщей. Всю кожу один тюбик не вылечит.",
  "onUse": [{ "problem": "skin", "add": -12 }] }
```

Поле `limits` обязательное. Это честная приписка, которую игрок видит до покупки:
что предмет не гарантирует. Для товаров за реальные деньги вместо `coins`
пишется `"price": { "iap": "код_товара" }`. Предмет без `price` не продаётся,
его можно только получить: подарком за день или эффектом `item`.

## Иконки

`plus`, `close`, `check`, `up`, `down`, `bolt`, `coin`, `heart`, `mirror`, `chat`, `feed`,
`bag`, `sunrise`, `sun`, `sunset`, `moon`, `drop`, `dumbbell`, `tooth`, `scissors`, `shirt`,
`spine`, `tube`, `bulb`, `clock`, `flame`, `lock`, `gum`, `note`.

## Чего движок пока не умеет

- Отправка фото в чат.
- Несколько языков: тексты сейчас только на русском.
- Покупки за реальные деньги: есть формат и заготовка сервера, проверки в сторах нет.
- Посты в ленте с кнопками прямо в ленте: сейчас выбор делается карточкой, а пост попадает в ленту эффектом `rumor`.
- Реферальная ссылка и кнопка «Сообщить о полной версии» на экране конца демо.
