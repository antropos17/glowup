# Контент игры

Здесь лежит всё, что пишет сценарий. Движок читает эти файлы как есть.

Сейчас в игре день 1 из `demo-7-days.md`: `cards/day1.json`. Дни 2–7 кладутся
рядом отдельными файлами, после этого в `balance.json` поднимается `contentDays`.

Как писать карточки, условия и эффекты: `docs/CONTENT_FORMAT.md`.
Проверка, что контент цел: `npm run check:content`.
